# Casos de Uso

## CU-01 Capturar dataset

El usuario selecciona una clase y captura imagenes o secuencias desde la camara.

## CU-02 Entrenar modelo

El desarrollador ejecuta scripts de entrenamiento con el dataset local.

## CU-03 Reconocer senna

La app procesa la camara, ejecuta el modelo y muestra una prediccion.

## CU-04 Reproducir traduccion

La app convierte el texto reconocido en salida de voz.
