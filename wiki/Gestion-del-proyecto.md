# Gestion del Proyecto

La gestion de SignVoice Colombia se organiza bajo la tecnica de **prototipado evolutivo**, apoyada por una herramienta colaborativa como GitHub Projects, Trello, Jira o GitLab.

## Objetivo

Reflejar un entorno real de trabajo con backlog, tareas, fechas, sprints, seguimiento, evidencias de pruebas y trazabilidad de avances.

## Tablero recomendado

Columnas:

| Columna | Uso |
| --- | --- |
| Product Backlog | Historias y mejoras pendientes |
| Sprint Backlog | Tareas seleccionadas para el sprint actual |
| En progreso | Trabajo en implementacion |
| Revision / Pruebas | Tareas terminadas pendientes de validar |
| Hecho | Tareas aprobadas con evidencia |

Vista adicional recomendada:

| Vista | Uso |
| --- | --- |
| QA / Pruebas | Gestion de casos de prueba, defectos y revalidaciones |

## Campos del tablero

| Campo | Tipo sugerido |
| --- | --- |
| Prioridad | Alta, Media, Baja |
| Sprint | Sprint 1, Sprint 2, Sprint 3, Sprint 4 |
| Tipo | Historia, Tarea, Bug, Prueba, Documentacion |
| Fecha inicio | Fecha |
| Fecha fin | Fecha |
| Responsable | Texto o usuario |
| Evidencia | Ruta, enlace o adjunto |
