# Configuracion del Entorno

## Python

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Android

Abrir `frontend/android` en Android Studio y sincronizar Gradle.

## Git

Trabajar desde `develop` y crear ramas `feature/*` o `prototype/*` segun corresponda.
