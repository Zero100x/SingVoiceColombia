# Prototipado Evolutivo

## Principio

El proyecto se construye mediante versiones incrementales. Cada prototipo debe ser ejecutable, medible y documentado, aunque no tenga todas las funciones finales.

## Iteraciones

| Iteracion | Rama sugerida | Resultado esperado |
| --- | --- | --- |
| Iteracion 1 | `prototype/v0.1-base` | Captura de dataset y estructura inicial. |
| Iteracion 2 | `feature/android-ui-v0.2` | Mejoras visuales y flujo de uso. |
| Iteracion 3 | `feature/tflite-recognition-v0.3` | Reconocimiento funcional integrado. |
| Iteracion 4 | `prototype/dynamic-signs-v0.4` | Prueba de reconocimiento dinamico. |
| Iteracion 5 | `feature/evaluation-v0.5` | Validacion, metricas y ajustes finales. |

## Criterios por iteracion

- Definir objetivo.
- Implementar incremento pequeno.
- Probar con datos reales.
- Documentar resultados en `CHANGELOG.md`.
- Registrar hallazgos en la wiki.

## Evidencias

Las evidencias pueden incluir:

- screenshots en `resources/screenshots`
- matrices de confusion
- reportes de clasificacion
- videos o capturas externas referenciadas en documentacion
