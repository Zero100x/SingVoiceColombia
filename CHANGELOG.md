# Changelog

Todas las mejoras importantes del proyecto se documentan en este archivo. El proyecto sigue versionamiento semantico adaptado a prototipos academicos.

## [v0.1.0] - 2026-05-07

### Agregado

- Estructura profesional del repositorio por dominios: frontend, IA, datasets, documentacion, recursos y backend futuro.
- App Android nativa como primer frontend funcional.
- Scripts Python para captura, extraccion de caracteristicas, entrenamiento e inferencia.
- Documentacion tecnica, wiki base y guias de colaboracion.
- Flujo Git Flow con ramas `main`, `develop`, `feature/*`, `hotfix/*` y `prototype/*`.

### Cambiado

- Se reorganizaron carpetas originales bajo una arquitectura escalable.
- Se actualizaron rutas internas de scripts Python para la nueva estructura.

### No versionado

- Datasets locales, entornos virtuales, caches, builds y artefactos pesados de modelos quedan fuera de Git.

## [v0.2.0] - Planificado

- Mejoras de interfaz Android y flujo de usuario.
- Seccion de evidencias con screenshots.
- Pruebas basicas de integracion Android.

## [v0.3.0] - Planificado

- Validacion de precision y reporte de metricas reproducibles.

## [v0.4.0] - Planificado
