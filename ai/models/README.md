# Modelos

Carpeta destinada a artefactos generados por entrenamiento.

Se ignoran por defecto:

- modelos `.h5`, `.tflite`, `.pkl`, `.joblib`, `.keras`
- pesos y SavedModel
- archivos binarios grandes

Se pueden versionar:

- metadata `.json`
- reportes `.txt`
- historiales `.csv`
- matrices de confusion `.csv`
